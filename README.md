# Space App

Uma galeria de imagens inspiradas no espaço, criada com React. Explore fotos de galáxias, estrelas e outros temas astronômicos em uma interface com busca, categorias e visualização ampliada.

## Recursos

- Busca de imagens pelo título.
- Filtro por tags, que pode ser combinado com a busca.
- Visualização ampliada das imagens em uma janela modal.
- Botão para marcar e desmarcar imagens como favoritas.
- Seção de imagens populares.

## Tecnologias

- React
- Vite
- styled-components

As imagens e os dados da galeria são carregados de arquivos locais do projeto. Não há backend ou banco de dados configurado.

## Como executar

É necessário ter o Node.js e o npm instalados.

```bash
npm install
npm run dev
```

O Vite exibirá no terminal o endereço local para abrir no navegador.

## Scripts disponíveis

| Comando           | Descrição                                    |
| ----------------- | -------------------------------------------- |
| `npm run dev`     | Inicia o servidor de desenvolvimento.        |
| `npm run build`   | Gera a versão de produção na pasta `dist`.   |
| `npm run preview` | Abre uma prévia local da versão de produção. |
| `npm run lint`    | Executa a verificação estática com Oxlint.   |
